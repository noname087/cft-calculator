# CFT Calculator (เครื่องคิดเลข CFT)

เครื่องคิดเลขลูกบาศก์ฟุต (CFT) และลูกบาศก์เมตร (CBM) จากขนาดกล่อง ทำงานในเบราว์เซอร์ ไม่ต้องติดตั้งหรือมี backend

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือเปิดผ่าน GitHub Pages ถ้าเปิดใช้งานไว้

1. เลือกหน่วยที่วัดขนาดกล่อง: มม., ซม., นิ้ว, ฟุต หรือ เมตร
2. กรอก กว้าง ยาว สูง และจำนวนกล่อง เพิ่มได้หลายรายการ
3. ดูผลรวม CFT / CBM ด้านบน และส่วน "วิธีคิด" ที่แสดงขั้นตอนของรายการที่เลือก
4. กด "คัดลอกสรุป" เพื่อนำข้อความสรุปไปใช้ต่อ

## สูตร

- `ลบ.ฟุต = กว้าง × ยาว × สูง` (วัดเป็นฟุต)
- วัดเป็นนิ้ว: ผลคูณ ÷ 1,728
- วัดเป็น ซม.: ผลคูณ ÷ 28,316.85
- วัดเป็น มม.: ผลคูณ ÷ 28,316,846.59
- `CBM = ลบ.ฟุต × 0.0283168` และ `ลบ.ฟุต = CBM × 35.3147`

ค่าแปลงหน่วยอิงจาก 1 ฟุต = 0.3048 ม. (1 ลบ.ฟุต = 0.028316846592 ลบ.ม.)

ค่าที่ได้เป็นการประมาณเบื้องต้น ควรยืนยันกับผู้ให้บริการขนส่งก่อนใช้คิดค่าระวาง
